# School Enrollment Management System

A professional Java desktop application for school enrollment management.

## Technology

- Java 21 compatibility
- JavaFX
- FXML
- CSS
- Maven
- PostgreSQL
- JDBC
- Flyway
- JUnit
- SLF4J
- Logback
- BCrypt

## Architecture

The application follows a layered architecture:

JavaFX / FXML
        ↓
Controller
        ↓
Service
        ↓
Repository / DAO
        ↓
PostgreSQL
